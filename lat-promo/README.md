# ريل مجلة العلم والعمل (LAT Magazine)

ريل طولي 9:16 (1080×1920)، طوله حوالي 30 ثانية، بنفس شكل ريل الفريق: خلفية كحلي فيها شبكة وإضاءة زرقا، خط Lalezar، لون أصفر للتمييز، وكابشن تحت.

**الفكرة:** الريل بيبدأ بأسئلة المقالات الأربعة كـ hook، وبعدها بيعرض المجلة ومواضيعها والاختبارات والشارات، ويخلص بالنداء «اقفل الاسكرول.. وقلّب الصفحة».

## الصوت: Google AI Studio (صوت بس، من غير موسيقى)

### الطريقة الأولى: الـ API
```bash
export GEMINI_API_KEY=...          # من https://aistudio.google.com/apikey
python3 tts_gemini.py              # طلب واحد للسكريبت كله، وبيتقسم على السكتات لـ audio/b1.wav … audio/b11.wav
node render.js                     # بيطلّع out/lat-reel.mp4 والمشاهد متظبطة على طول كل جملة
```

> الـ free tier بيسمح بـ 10 طلبات بس في اليوم لكل موديل، عشان كده السكريبت بيستخدم طلب واحد. ولو عايز طلب لكل جملة: `python3 tts_gemini.py --per-line`.

### الطريقة التانية: من موقع AI Studio بإيدك
1. ادخل aistudio.google.com، وبعدها **Generate speech**، واختار موديل TTS.
2. خلّي الوضع **Single-speaker** والصوت **Achird**. لو عايز صوت تاني قريب منه جرّب Umbriel أو Charon.
3. في **Style instructions** حط الـ `style` اللي في `script.json`.
4. ولّد كل جملة من الجمل اللي تحت لوحدها، ونزّلها باسمها (`b1.wav` … `b11.wav`) في فولدر `audio/`.
5. شغّل `node render.js`.

| # | الجملة |
|---|---|
| b1 | سؤال سريع.. |
| b2 | هو المؤمن ممكن يتعب نفسيًا؟ |
| b3 | طب رقبتك بتوجعك ليه بعد المذاكرة؟ |
| b4 | والذكاء الاصطناعي.. بيساعدك تفكّر، ولا بيفكّر بدالك؟ |
| b5 | وفيه امتحان.. مفيهوش ملخصات، ولا ليلة امتحان. |
| b6 | الإجابات دي كلها.. في مجلة العلم والعمل. |
| b7 | مقالات قصيرة بتفرق معاك.. في دينك، وصحتك، ومذاكرتك. |
| b8 | وكل مقال بيتقري في دقايق. |
| b9 | وفي آخر كل مقال سؤالين، تختبر بيهم نفسك وتجمع شارات. |
| b10 | اقفل الاسكرول شوية.. |
| b11 | وقلّب الصفحة. اللينك مستنيك. |

## الملفات
- `script.json`: الجمل والكابشن (الكلمة اللي بين `{}` بتطلع صفرا) وإعدادات الصوت.
- `promo.html`: الفيديو نفسه. افتحه في المتصفح وهتشوف preview بيشتغل لوحده.
- `render.js`: بيطلّع MP4 بـ 30fps. الصوت بيتحط في وقته ومن غير أي موسيقى.
- `assets/pages/`: صفحات من المجلة.
